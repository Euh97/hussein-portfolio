# Hussein Hossaini — Static Portfolio

This version uses only HTML, CSS, and JavaScript.

## Open locally

Double-click `index.html`. No installation, npm, build step, or server is required.

## Files

- `index.html` — page content and structure
- `style.css` — complete design and responsive layout
- `script.js` — current year and smooth anchor scrolling

## Publish

The folder can be deployed directly to GitHub Pages, Netlify, Cloudflare Pages, or any basic web host.
